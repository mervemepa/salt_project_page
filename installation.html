Installation: Meshwork Prototype

This page documents the installation process of the Meshwork prototype, including technical steps, visuals, and conceptual context of the piece.

Work Description

Meshwork is a media installation that explores technological entanglements through physical infrastructures. The sensors react to environmental changes, while the embedded microcontrollers trace invisible threads of interaction.
